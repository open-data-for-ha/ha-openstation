# Changelog

## 0.2.4 (2026-11-05)

- README: installing starts with searching in the Marketplace or HACS, now that the
  integration is in the default catalog. Adding it from a link stays as a fallback.

## 0.2.3 (2026-11-04)

- README: buttons that open the repository and the setup in Home Assistant, and a corrected
  note on restarting after installing through the Marketplace.
- Release tags no longer carry a `v` prefix, so they match the manifest version.

## 0.2.2 (2026-11-04)

- Tested on Home Assistant 2026.11. The README covers installing through the Marketplace.
- Added the public transport category for browsing the Marketplace.

## 0.2.1 (2026-11-04)

- German README, followed by the English one.

## 0.2.0 (2026-11-04)

- Crossed-out icons for escalators and travelators out of service, and for their summary
  sensors.

## 0.1.0 (2026-11-04)

First release.

- One device per selected German station, with a binary sensor per elevator, escalator
  and travelator.
- Sensors counting the equipment out of service per station and type.
